# 第 1 步：提问

目的：了解用户的背景，用来决定资料库要建哪些部分、记录范围是什么。

## 怎么问

- 分 5 轮，**一次只发一轮**，等用户回答完再发下一轮
- 每个问题都编号，用户可以只回编号和答案，也可以说“跳过”
- 回答太笼统就追问一句，例如“做运营”可以追问“主要做活动、内容，还是用户增长？”
- 用户说“随便”“你看着办”时，给一个默认选项让他确认，不要替他决定
- 用户问“为什么要问这个”时，一句话说明用途

## 第 1 轮：你是谁

1. 我怎么称呼你？
2. 你现在是什么身份？可以多选：上班 / 自由职业 / 创业 / 做内容（自媒体）/ 学生 / 其他
3. 你做什么岗位、在什么行业？做了几年？（上班的话，愿意也可以说在哪家公司，不说也没关系）
   （例：互联网公司的产品经理，3 年；自己做 APP，1 年）

## 第 2 轮：你每天做什么

4. 你手上正在做哪些**项目**？就是有明确目标、做完会结束的事。（例：Q3 大促、做一个 APP、准备述职）
5. 你**长期负责**哪些事？就是不会结束、要一直管的事。（例：带团队、管客户、运营一个账号、自己的健康）
6. 你的工作时间主要花在哪？可以多选：和人沟通 / 写方案、做 PPT / 推进项目 / 分析数据 / 写代码 / 做内容 / 销售、谈客户 / 其他
7. 你**最常做、最费时间**的 3 件事是什么？

## 第 3 轮：你想要什么

8. 未来一年，你最想达成的 1–3 个目标是什么？
9. 现在最让你头疼的是什么？
10. 你最希望这个数据库帮你做到什么？可以多选：
    复盘总结 / 自动写周报、述职 / 积累晋升和跳槽的材料 / 找内容选题 / 做事更快、少踩坑 / 更了解自己 / 其他

## 第 4 轮：生活（全部可选）

11. 除了工作，你还想记录这些吗？可以多选，也可以都不要：
    财务（收支、投资）/ 健康运动 / 学习读书 / 兴趣和生活小事 / 情绪和状态 / 感情和家庭
12. 选了的，多久记一次？（例：财务每周一次、运动每天一次）

## 第 5 轮：设置

13. 你平时用哪些 AI 工具？我们现在用的是哪个？
14. 你会在几台电脑上用？分别怎么称呼？（例：家里、公司。名字只用英文字母和数字，例如 `Home`、`Work`）
15. 你有 GitHub 账号吗？没有也没关系，下一步我带你注册。
16. 每天、每周的成长报告，你想怎么收？到点自动生成（有提醒）/ 发邮件 / 先不要，我想看的时候说一声
17. 工作上有没有**明确不想记**的内容？（例：客户名单、公司财务数据。不确定可以先跳过，以后随时加）

## 问完之后

用 10 行以内复述你理解的内容，问一句“对吗？有要改的吗？”。用户确认后再进入下一步。

## 回答怎么用

| 回答 | 用在哪 |
|---|---|
| 1–3 | `我是谁/基本信息.md` |
| 2、6 | 从 `templates/系统/模块库.md` 选要建的模块。上班的人加“职场”模块；做内容的人加“内容创作”模块；可以叠加 |
| 4 | 在 `项目/` 下每个项目建一个文件 |
| 5 | 在 `领域/` 下每个领域建一个文件 |
| 7 | 写进 `能力/README.md` 的能力地图，标 💡（以后重点沉淀） |
| 8 | `目标与复盘/年度目标.md` |
| 9、10 | `我是谁/基本信息.md` 的“我想要什么”；也决定首日报告和每日报告重点写什么 |
| 11、12 | 选了的才建 `领域/财务.md` 这类文件 |
| 13–16 | `设置.md` |
| 17 | `我是谁/记录范围.md` 的“不记清单” |
