# 第 5 步：接入 AI 工具（以及以后接入新工具、新电脑）

目的：让用户在**任何项目、任何对话**里用 AI 做完事，AI 都知道要往资料库里记。

具体写什么、写在哪，都在资料库里的 `系统/接入说明.md`。那份文件放在资料库里，是为了以后其他工具、其他电脑也能读到它。下面是流程。

## 接入当前工具

1. 判断你自己是哪个工具：Claude Code、Codex、Cursor、WorkBuddy、DeepSeek Harness，还是其他
2. 读 `系统/接入说明.md`，找到这个工具的全局规则位置，以及要写的那段文字
3. **先告诉用户**：“我要在 `<位置>` 新增这样一段（展示内容），这样你以后在别的项目里用我，我也会记录。可以吗？”
4. 先看规则文件里是不是**已经接了另一个资料库**（比如用户之前自己建过一个）。是的话不要直接追加，否则 AI 会不知道该记到哪个库。问用户：换成新的、保留旧的，还是先不接
5. 用户同意后再写：
   - 文件已存在：在**末尾追加**，不改、不删原来的内容
   - 文件不存在：新建
   - 已经有这段规则（比如之前接入过）：不重复写，告诉用户“已经接入过了”
6. 自测，三项都通过才算接入成功：
   - 规则文件里确实有这段内容
   - 资料库能 `git pull` 和 `git push`（用户跳过了 GitHub 的话，这一项跳过，并提醒他：现在数据只在这台电脑上，换电脑会丢，以后说“帮我建 GitHub 仓库”随时补上）
   - 请用户新开一个对话问“你知道我的个人成长资料库吗？做完事要记到哪？”，答得上来就成功了
7. 不知道这个工具的全局规则写在哪：就让用户把那段文字粘贴到这个工具的“自定义指令 / 规则 / 记忆”设置里，告诉他大概在哪找；找不到就让他截图给你看

**只接入当前这个工具**。其他工具，用户以后在那个工具里说一句“接入我的成长资料库”，再照这个流程做。

## 接入新电脑

用户在新电脑的 AI 工具里说“把我的成长资料库接到这台电脑上”，并给出仓库地址：

1. 问这台电脑叫什么（英文字母和数字，例如 `Work`），记进 `设置.md` 的电脑列表
2. 把仓库下载到这台电脑（`git clone`）。第一次可能要登录 GitHub，见 `references/05-GitHub.md`
3. 按上面“接入当前工具”的流程，接入这台电脑上的工具
4. 推送一次，确认能同步

## 只能聊天、不能写文件的 AI（网页版 ChatGPT、DeepSeek、豆包、Grok 等）

这类 AI 改不了资料库，只能“存档”：用户说“存档”时，它按事件记录的格式输出一段总结，用户复制给能写文件的 AI，前面加一句“记一下：”。要写进它们自定义指令里的文字，见 `系统/接入说明.md` 最后一节。
