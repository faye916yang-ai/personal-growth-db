# 个人成长数据库

**用 AI 做事，AI 顺手把你记下来。越用越像你，最后长成一个会替你做事的 AI 版的你。**

这是一个 AI Skill。装好后，对你的 AI 说一句“帮我搭建个人成长数据库”，它会先问你几轮问题，再为你搭出一个**只属于你**的成长数据库。之后你照常用 AI 干活，它会自动记下你做了什么、收获了什么、踩了什么坑，慢慢沉淀成你的做事方法和 SOP。

## 它能帮你什么

- **每天自动记录**：不用写日记。用 AI 做完一件事，AI 自己记下来
- **每日成长报告**：今天做了什么、收获、踩的坑、**能力的变化**，让你每天都看到“我又长了一点”
- **周六复盘、月度复盘**：这周做成了什么、哪些坑重复踩了、这个月我变了什么
- **长出你的能力**：同一类事做过几次，AI 帮你整理成 SOP；SOP 每用一次就改进一次
- **越来越懂你**：AI 会发现你的做事习惯，**你确认后**才写进“我是谁”
- **一键生成**：周报、述职、简历、个人画像，从平时的记录里直接生成
- **换电脑、换工具都不丢**：数据放在你自己的 GitHub 私有仓库，所有电脑、所有 AI 工具读的是同一份

## 适合谁

职场人、自由职业者、超级个体、内容创作者。身份可以叠加：上班又做副业，两边都能记。

## 安装

**最简单的方法**：把下面这段话发给你的 AI 工具。

```
请把 https://github.com/faye916yang-ai/personal-growth-db 下载下来，安装成你的 Skill。
如果你不支持 Skill，就直接读里面的 SKILL.md，照着做。
```

**手动安装**：把整个仓库下载到对应工具的 Skill 文件夹，文件夹名用 `personal-growth-db`：

## 开始使用

装好后，对 AI 说：

```
帮我搭建个人成长数据库
```

大约 5–10 分钟，AI 会带你走完 7 步：

1. 分 5 轮问你问题：你是谁、每天做什么、想要什么、要不要记生活、用哪些工具
2. （可选）看一下你电脑上已有的资料，把做过的事整理进来。你选扫不扫、扫哪些文件夹，扫之前会先告诉你大概要用多少额度
3. 生成你的资料库
4. 建 GitHub 私有仓库（没有账号会带你注册；登录这一步需要你自己操作）
5. 接入你正在用的 AI 工具
6. 给你第一份成长报告：你已经做过的事、你已经有的做事方法
7. 设置每日、每周的报告，教你日常怎么用

## 日常怎么用

照常用 AI 干活就行。常用的几句话：

| 你说 | AI 做什么 |
|---|---|
| 记一下：…… | 记进今天的日志 |
| 收工 | 整理今天的记录，出成长报告 |
| 复盘 | 写本周复盘 |
| 生成周报 / 述职 / 简历 | 从记录里直接生成 |
| 把这个整理成能力 | 把刚做完的事写成 SOP |
| 接入这个工具 | 在另一个 AI 工具里接入资料库 |

遇到问题，在任何一个 AI 对话框里直接问就行。

## 资料库长什么样

按“做的事”分（PARA 方法），再加上从记录长成能力的四层：

```
我是谁/       你的基本信息、做事风格、原则、方法论（你确认过的才算）
每日/         每天的记录和成长报告
项目/         有目标、会结束的事
领域/         长期负责的事
资源/         提示词、模板、资料
归档/         做完的事
成长/         踩坑避坑库、周报、月报
能力/         能力地图：SOP、检查清单、判断框架、模板
产出/         一键生成的周报、述职、简历
系统/         规则和说明（Skill 升级时只更新这里）
```

一开始只建你需要的部分，用到某类事时才长出对应的模块。

## 隐私和安全

- 数据在**你自己的 GitHub 私有仓库**里，这个 Skill 的作者看不到
- 密码、密钥、证书，以及客户的手机号、身份证这类个人信息，AI 不会记
- 工作上不想记的内容，可以列进“不记清单”
- 工作资料单独存放：离职时归档工作资料，成长部分完整带走
- AI 修改你电脑上资料库以外的文件之前，都会先告诉你要改什么，你同意了才改
