# 能力

资料库的最上层：把你做过、验证过的事，固化成**任何 AI 拿到就能照着做**的东西。

- **对 AI**：不管用哪个工具，做某类事之前先来这里找，有就照着做，不用你从头解释
- **对你**：一目了然，不用每次重新摸索；以后也能分享给别人、带新人

能力**只从你自己做过的事里长出来**，不放别人的通用模板。

## 能力的五种形式

| 形式 | 是什么 | 例子 |
|---|---|---|
| **SOP** | 一步一步的流程 | 写周报、做月度数据分析、招聘面试 |
| **检查清单** | 做完前逐项打勾 | 发版前检查、发邮件给大客户前检查 |
| **判断框架** | 遇到某类选择时怎么判断 | 一个需求做不做、一个机会接不接 |
| **模板** | 拿来就填的格式 | 汇报 PPT 结构、复盘文档结构 |
| **配方** | 工具 + 提示词 + 参数的组合 | 用哪个 AI、什么提示词做 PPT 配图 |

文件命名：`能力/<领域>/<形式>-<名字>.md`，例如 `能力/汇报/SOP-写周报.md`

## 能力怎么长出来

1. 做事时写事件记录（`每日/`）
2. 同一类事做过 2 次，地图上标 💡
3. 做第 3 次前，AI 主动提议：这次边做边整理成 SOP
4. 每照着用一遍，在文末“执行记录”加一行；哪一步不顺，AI 提议怎么改，你同意后修改，并写进“修改记录”
5. 很久没用、或者已经不适用的，AI 会问你要不要淘汰（移到末尾“已淘汰”，不删除）
6. 你也可以随时说“把这个整理成能力”

一份写得好的 SOP 长什么样，可以参考 `系统/示例SOP.md`。
