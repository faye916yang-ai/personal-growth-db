# 每日

整个资料库的**心脏**：每天做成了哪些事、踩了什么坑、学到了什么，都先记在这里。踩坑库、能力、“我是谁”都从这里提炼出来。

**只追加，永不改写。**

## 文件命名
`每日/YYYY-MM/YYYY-MM-DD-<电脑名>.md`，例如 `每日/2026-03/2026-03-05-Work.md`

每台电脑每天一个文件，两台电脑同时写也不会冲突。电脑名见 `设置.md`。

## 按“一件事”记
一件事 = 一个有明确目标的工作，可能包含很多条指令、跨好几个对话。**一件事写一条事件记录**，不是每条指令都记。

## 模板

```markdown
# 2026-03-05｜Work

## 事件

### [Q1 述职] 写完述职 PPT ✅
- **目标**：周五前交出 15 页述职 PPT
- **过程**：从资料库的晋升证据里取素材 → AI 搭框架 → 补数据 → 上级预审
- **卡点和突破**：
  - 一开始按时间顺序罗列做过的事，上级说看不出重点；改成“3 个关键成果 + 数据”
  - 以后：述职先列成果和数据，再讲过程
- **结果**：交了，上级说比上次清楚
- **收获**：述职的结构是“结果 → 方法 → 下一步”
- **值得留下的**：述职结构可以整理成模板｜可以写进晋升证据：用户留存提升 8%

### [新功能上线] 和研发对齐需求 🔄 进行中
- **目标**：
- **做到哪了**：
- **下一步**：

## 记一下
（随口说的零散内容：想法、心情、看到的好东西）

## 今日成长报告
（收工或定时报告时由 AI 写，格式见 AGENTS.md）
```

状态标记：✅ 完成｜🔄 进行中｜⏸ 暂停｜❌ 放弃
