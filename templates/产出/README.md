# 产出

平时记下来的东西，一句话就能变成能直接用的材料。生成的文件放在这里。

| 你说 | AI 从哪取材料 | 放在 |
|---|---|---|
| 生成周报 | 本周 `每日/` 的事件记录 | `产出/周报/YYYY-Www.md` |
| 生成述职 / 年终总结 | `成长/晋升证据.md`、`项目/`、这段时间的周报 | `产出/述职-YYYY-MM.md` |
| 生成简历 / 更新简历 | `我是谁/基本信息.md`、`成长/晋升证据.md`、`归档/` 里的项目 | `产出/简历.md` |
| 生成我的画像 | `我是谁/` 的全部、`能力/README.md`、最近的月报 | `产出/我的画像.md` |
| 生成本月复盘 | 见 `AGENTS.md` 的“月度复盘” | `成长/月报/` |

## 规则
- 只用记录里有的事实和数据，**不编造**；缺的数据标出来，问你要
- 给上级、给外部的材料，不放“不记清单”里的内容
- 生成后在对话里给你看，你确认后再保存
