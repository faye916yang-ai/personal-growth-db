# 使用说明（给自己看的一页）

## 它是什么
一个会自己长大的“AI 版的我”。你照常用 AI 做事，AI 会顺手记下你做了什么、收获、踩的坑，慢慢沉淀成你的做事方法和 SOP。

## 每天怎么用
**什么都不用多做。** 照常用 AI 干活，一件事做完，AI 会自己记下来、推送到 GitHub。

## 常用口令
| 你说 | AI 做什么 |
|---|---|
| 记一下：…… | 把这句话记进今天的日志 |
| 收工 | 整理今天的记录，出今日成长报告 |
| 复盘 | 写本周复盘（默认每周六晚上会自动出） |
| 月度复盘 | 写本月复盘：这个月我变了什么 |
| 生成周报 / 述职 / 简历 / 我的画像 | 从记录里直接生成 |
| 把这个整理成能力 | 把刚做完的事写成 SOP |
| 深度导入 XX | 把电脑上某个项目的细节整理进来 |
| 接入这个工具 | 在另一个 AI 工具里说，接入资料库 |
| 资料库体检 | 检查记录和推送是否正常 |

在网页版 ChatGPT、DeepSeek 这类只能聊天的 AI 里：说“存档”，把它给的总结复制到能写文件的 AI 里，前面加“记一下：”。

## 你要确认的
- 每周复盘最后会问你最多 3 条“我发现你的做事习惯”，回“1 对 2 改成…… 3 不对”就行，不回也没关系
- AI 要加新的大模块时会先问你

## 去哪看
| 想看 | 去哪 |
|---|---|
| 今天、某天做了什么 | `每日/` |
| 我是怎样的人 | `我是谁/` |
| 我会做哪些事、SOP | `能力/README.md` |
| 踩过的坑 | `成长/踩坑避坑库.md` |
| 每周、每月复盘 | `成长/周报/`、`成长/月报/` |
| 周报、述职、简历 | `产出/` |

## 遇到问题
在任何一个 AI 对话框里直接问就行，例如“我的成长资料库今天没记录，怎么回事？”。AI 会去读 `系统/常见问题.md`。
