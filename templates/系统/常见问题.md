# 常见问题

主人问到资料库的问题时，AI 先读这里。按“现象 → 原因 → 怎么办”排查，能自己解决的直接解决，需要主人操作的一步一步带他做。

## 做完事 AI 没有记录

1. **这个工具没接入**：查 `设置.md` 的“AI 工具”表，没接入就按 `系统/接入说明.md` 接入
2. **接入了但没生效**：在这个工具里新开一个对话（已经开着的对话读不到新规则），问“你知道我的个人成长资料库吗？”。答不上来，就检查全局规则文件里有没有那段文字
3. **AI 判断不在记录范围**：看 `我是谁/记录范围.md`，需要的话加进去
4. **临时补救**：说“记一下：今天做了……”

## 推送失败

| 提示 | 怎么办 |
|---|---|
| rejected、fetch first、non-fast-forward | 先 `git pull --rebase`，再 `git push` |
| 有冲突（conflict） | 两台电脑改了同一个文件。打开冲突的文件，两边的内容都保留，再提交。每日日志按电脑分文件，一般不会冲突 |
| 要密码 / Authentication failed | GitHub 不支持用密码推送。装 GitHub CLI 运行 `gh auth login`，或者用 GitHub Desktop 登录一次 |
| Repository not found | 仓库地址不对，或者这台电脑登录的 GitHub 账号不是仓库的主人 |
| 没网 | 记录先存在本地，下次有网时推送。告诉主人“还没推送” |

推送失败时**不要丢掉记录**：记录已经写在本地文件里，告诉主人还没推送就行。

## 换电脑、加电脑
在新电脑的 AI 工具里说“把我的成长资料库接到这台电脑上”，并给出仓库地址。见 `系统/接入说明.md` 的“接入新电脑”。

## 换 AI 工具、加 AI 工具
在新工具里打开资料库文件夹，说“接入这个工具”。

## 定时报告没收到
- 定时那个时间电脑是开着的吗？在电脑上运行的工具，关机或休眠时不会执行
- 定时任务还在吗？在工具的定时任务列表里看一下
- 先手动说一句“出今天的成长报告”，确认报告本身能生成

## 不小心记了不该记的（密码、客户信息）
1. 马上从文件里删掉，提交、推送
2. 但是 git 历史里还有。如果是密码、密钥，**直接去改密码、作废密钥**，这是最稳的做法
3. 把这类内容加进 `我是谁/记录范围.md` 的“不记清单”

## 资料库越来越乱
说“资料库体检”或“月度复盘”，AI 会找出重复的、过时的、该拆开的部分，逐条问你。

## 想让 AI 少问我一点
说“以后 XX 这类事直接记，不用问”，AI 会把它写进 `我是谁/记录范围.md`。

## 怎么升级这个 Skill
升级只更新 `AGENTS.md`、`CLAUDE.md` 和 `系统/` 这几个文件，你的记录、SOP、画像都不会动。说“升级我的成长数据库”，AI 会先列出要更新的文件，你同意后再更新。
