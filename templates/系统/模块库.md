# 模块库

资料库一开始只有核心部分。下面这些模块，**用到时才建**：搭建时按主人的身份和选择建一部分；之后主人第一次做到某类事时，再建对应的模块。

建模块的规矩：
- 小模块（一个新文件）可以直接建，事后告诉主人
- 新方向、新的大模块，先问一句“要不要加 XX？”
- 建了就在 `成长/结构变化记录.md` 记一笔；同时更新 `我是谁/记录范围.md`

身份可以叠加：上班又做副业的人，职场模块和副业对应的模块都建。

## 职场（上班的人）

| 模块 | 文件 | 什么时候建 |
|---|---|---|
| 工作资料 | `工作资料/<公司名>/`（用户没说公司名，就用 `工作资料/当前工作/`） | 搭建时。公司的具体资料只记摘要（客户、数据、内部文档）；离职时整个移到 `归档/` |
| 晋升证据 | `成长/晋升证据.md` | 搭建时。格式：日期、做成了什么、数据、谁认可了 |
| 周报和述职 | `产出/周报/`、`产出/述职-*.md` | 第一次生成时 |
| 会议和决策 | `领域/会议与决策.md` | 第一次记会议时：开了什么会、定了什么、为什么、谁负责 |
| 向上管理 | `领域/向上管理.md` | 第一次记和上级的沟通时：上级的期望、反馈、1 对 1 记录 |
| 职业规划 | `目标与复盘/职业规划.md` | 主人聊到升职、跳槽、转行时：想去哪、差哪些能力 |
| 简历 | `产出/简历.md` | 第一次生成时，之后随晋升证据更新 |
| 带团队 | `领域/带团队.md` | 主人是管理者时：成员情况、给过的反馈、团队的做法 |

按岗位常见的模块（遇到时再建）：

| 岗位 | 可能用到 |
|---|---|
| 销售、商务 | `领域/客户关系.md`（不记个人信息）、`资源/话术库.md` |
| 产品 | `资源/需求与评审.md`、项目复盘 |
| 运营、市场 | `资源/活动案例库.md`、`领域/数据看板.md` |
| 财务、行政、HR | 报表和流程类的 SOP 放进 `能力/` |
| 常做 PPT、写方案的 | `资源/汇报模板.md` |
| 技术 | `资源/技术笔记.md`、踩坑库里的技术分类 |

## 内容创作（做自媒体的人）

| 模块 | 文件 |
|---|---|
| 账号 | `领域/账号-<平台>-<账号名>.md`：定位、受众、数据、做法 |
| 口吻风格 | `我是谁/口吻风格.md`：说话方式、常用表达。写对外文案时严格按它 |
| 选题库 | `资源/选题库.md`：日期、选题、来源、适合哪个账号、状态 |
| 爆款库 | `资源/爆款库.md`：数据好的内容，拆解为什么火，以及怎么改编 |
| 发布记录 | `资源/发布记录.md`：发了什么、哪天、数据 |
| 逐字稿 | `资源/逐字稿/`：真实说过的话，用来学习主人的说话方式 |

## 做产品、开发、创业

| 模块 | 文件 |
|---|---|
| 产品 | 每个产品是一个项目：`项目/<产品名>.md`，或者 `项目/<产品名>/`（概况、决策记录、想法池） |
| 方法手册 | `资源/<方向>手册.md`，例如出海手册、增长手册：从实践里沉淀的方法论 |

## 生活（主人选了才建）

| 模块 | 文件 |
|---|---|
| 财务 | `领域/财务.md`：收支、投资、理财学习。**只记数字和规划，不记卡号、账号、密码** |
| 健康 | `领域/健康.md`：运动、睡眠、精力 |
| 学习 | `领域/学习.md`：读书、上课 |
| 兴趣与日常 | `领域/兴趣与日常.md` |
| 感情与家庭 | `领域/感情与家庭.md`：伴侣、家人、重要的关系和相处方式 |
| 情绪和状态 | `领域/情绪与状态.md`：每天一句心情、精力打分 |
