# 定时任务

三份成长报告的提示词。在你用的 AI 工具里建定时任务（不同工具叫法：定时任务、自动化、Scheduled tasks、Routines），把对应的提示词原样贴进去。

时间以 `设置.md` 为准，默认：每日 22:00，周复盘每周六 20:00，月度复盘每月最后一天。

- 在电脑上运行的工具，**电脑开着**定时任务才会执行；有的工具还要求 App 开着
- 很多工具每次运行都是一个新的对话，报告在工具的定时任务列表里看；报告同时会写进资料库当天的日志
- 工具不支持定时任务的话，打开 AI 时说一句“出今天的成长报告”“复盘”就行

## 1. 每日成长报告

```
打开我的个人成长数据库（<资料库路径>），先 git pull。
读 AGENTS.md，再读 每日/ 下今天的所有日志（每台电脑一个文件）。
按 AGENTS.md 里“每日成长报告”的格式写今天的成长报告，追加到今天本机的日志末尾，然后推送。
最后把报告发给我。
如果今天没有任何记录，就告诉我“今天资料库没有更新”，提醒我把今天的事记下来。
```

## 2. 周复盘

```
打开我的个人成长数据库（<资料库路径>），先 git pull。
读 AGENTS.md，按“周复盘”的流程写本周复盘，存进 成长/周报/，推送。
最后把复盘发给我，包括最多 3 条需要我确认的做事习惯。
```

## 3. 月度复盘

```
打开我的个人成长数据库（<资料库路径>），先 git pull。
读 AGENTS.md，按“月度复盘”的流程写本月复盘，存进 成长/月报/，推送。
最后把复盘发给我，资料库体检里建议淘汰或合并的条目逐条列出来问我。
```

## 发邮件

AI 工具能发邮件（连接了邮箱）时，在提示词最后加一句：“并把报告发到我的邮箱 <邮箱>”。邮箱地址只写在你自己电脑的定时任务里，不要写进资料库。
